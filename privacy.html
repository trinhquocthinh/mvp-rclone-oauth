Privacy Policy

Last updated: October 8, 2026

Purpose

Homelab Rclone Backup is a personal application used to back up and restore data from privately managed servers using Google Drive and rclone.

Google Drive Access

The application requests Google Drive access to create, read, update, and delete backup files as part of backup, retention, and disaster recovery operations.

Data Storage and Security

Backup files are encrypted client-side using rclone crypt before being uploaded to Google Drive. OAuth credentials are stored locally on the server and are not published on this website.

Data Sharing

Google Drive is used as the backup storage provider. Google user data is not sold or shared for advertising purposes.

Data Retention

Backup files are retained according to the configured backup retention policy and deleted when no longer required.

Revoking Access

Access can be revoked through Google Account security settings. Stored backup files can be deleted by the account owner.
